# Curated mainstream-domain list for high-credibility labeling.
#
# Purpose: counterpart to the Iffy+ low-credibility list. A tweet whose URLs
# resolve to a domain in this file is labeled high-credibility. Tweets whose
# URLs match neither list remain unlabeled (per CLAUDE.md §Labeling).
#
# Selection criteria for v0 (to be refined in Phase 1):
#   - U.S./international general-news outlets widely rated "High" or "Very High"
#     factual on Media Bias/Fact Check.
#   - Span the partisan spectrum where credible outlets exist on both sides;
#     credibility is about factual reporting, not absence of bias.
#   - Wires (AP, Reuters), public broadcasters (NPR, PBS, BBC), and dedicated
#     fact-checking outlets included.
#   - National-only for v0; local-paper coverage is patchy and adds noise.
#
# Format: one bare domain per line (no scheme, no www, no trailing slash).
# Subdomains will be matched via tldextract registered-domain lookup at
# label time, so listing the registered domain is sufficient.
